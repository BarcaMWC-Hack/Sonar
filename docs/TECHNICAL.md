# Sonar | Phase 1 technical submission

Sonar assigns every tactical-video frame to home possession, away possession, dead ball or abstention. It uses tactical automatic tracking and Smart Tagging to decide when play is stopped, which team controls the ball during live play, and where possession boundaries belong.

## Possession rules and method

1. **Stoppages.** A logistic model uses motion, line crossings, ball visibility and restart geometry. Its regularization and feature set were chosen by held-out log loss between the two halves of this match. Its weights are fitted on the true dead-ball flags of 27 open matches from other competitions, not on this match: 7 Sportec/DFL IDSSE Bundesliga matches and 20 SkillCorner A-League broadcast-tracking matches (`tools/open_fit.py`, stored in `sonar/deadball_open_weights.json`). The IDSSE tracking never loses the ball, so it is first degraded the way this match's tracking loses it. That loss pattern was measured from aggregate gap statistics only: about 150 long gaps, mostly in stoppages. SkillCorner's broadcast tracking loses the ball itself, on 40.7% of frames. Scored leave-one-match-out on the 20 SkillCorner matches, this fit raised spellF1 from 0.367 to 0.402 over an earlier fit on this match's Smart Tagging weak labels, and was better on all 20. A two-state sequence decoder limits flicker. The edges are refined using ball crossings, movement changes and restart kicks. The organizer-documented pre-kickoff interval is enforced in output, separately from model fitting.
2. **Team in control.** A slow ball close to a player is stronger evidence than simple proximity. A switching cost prevents the answer from flipping during a loose ball or an ordinary pass. Team spacing, measured against each half's own baseline, provides evidence when ball evidence is weak. Smart Tagging provides a fallback for a live stretch without tracking evidence, and on the submitted file it decides none of the 98 live stretches. The switching cost of 3.0 was kept over 2.0: 2.0 adds short and quickly reversed possessions, and on the 20 SkillCorner matches, whose possession counts are close to this match's, 2.0 scored lower on 18 of 20.
3. **Change of possession.** For a decoded change during live play, the system searches a bounded interval for the new team's first touch or clear control after the old team's last local touch or control. It cannot move the change across a stoppage or neighboring change. A deflection can resemble a touch and remains a limitation. Restarts begin a new live stretch. The system emits X outside graded play. On graded frames it never abstains: where it has no evidence it writes the label the official scorer would carry forward anyway (the last label in that half, which can be D), so spellF1 is unchanged by construction and macroF1 cannot fall, since an X always counts as a miss there.

## Inputs and training disclosure

- **Organizer-supplied match assets used by the submission:** tactical tracking positions and metadata for one complete match, and its automatically generated Smart Tagging XML. Only graded frames are used: ungraded frames are blanked when the tracking is loaded, so no smoothing window can reach them. The team-shape fit uses only automatic evidence from this match. The team-shape fit uses tracking-derived control as weak supervision. Human-labeled examples used for model fitting or parameter selection from this match: **zero**.
- **Organizer public ground truth:** five minutes, used to check the fixed pipeline. It did not select a model, threshold or setting. The team did not use private ground truth or human-produced data about the fixture.
- **Other matches:** three anonymized Metrica Sports open sample games were used to benchmark candidate methods. The stoppage model is trained on public open data from other competitions:
  - seven Sportec/DFL IDSSE Bundesliga matches (Bassek, Rein, Weber and Memmert, "An integrated dataset of spatiotemporal and event data in elite soccer", *Scientific Data*, 2025; CC-BY 4.0), using the frame-level ball state;
  - twenty SkillCorner open-data A-League 2024/25 matches (SkillCorner, MIT licence), using "in play" as inside a SkillCorner phase of play.

  These matches were also used to compare candidate settings, always leave-one-match-out. Simulated tracking gaps were added to the IDSSE tracking only. The submitted generator reads only the organizer-supplied match assets above plus the stored stoppage weights; refitting those weights needs the public downloads (`tools/idsse_data.py`, `tools/skillcorner_data.py`).
- **Assets explored:** the broadcast stream was aligned in a feasibility study. The measured recovery of missing-ball frames was small and the replay cue missed its gate. Broadcast footage and tracking, homography, and pretrained models are outside the submitted pipeline. Learned sequence decoders (a bidirectional GRU, a logistic regression and a blend with the rule model) were trained on the open games and dropped: they gained on held-out games from one data provider but lost on another provider's games, so they did not generalise and could not be trusted on this match. Simpler possession variants (requiring the new team to keep control, team shape only where the ball is seen, merging spells under 1-2 s) were tested on the IDSSE matches with predicted dead periods and none improved on the release.

## Checks and limitations

The fixed file has 199,319 data rows, with 97 stoppages covering 48% of graded time and 277 possessions of mean 11.9 s. On the public pipeline check it scored **0.3789 spellF1** and **0.7612 macroF1**, with **21 predicted possessions** against **17 reference possessions**. The earlier weak-label build scored 0.4108 and 0.7545 there; the window is too small to separate them, and it did not inform the choice. The corresponding public spellF1 values are **0.3256** for smooth50 and **0.4242** for smooth125. The full-match score is determined by the organizers using private labels. Against this match's Smart Tagging weak labels, which it was never fitted on, the stoppage model's AUC is 0.82. On five time-block folds of graded frames with a 10 s gap (`sonar/splits.py`), the team-shape model's mean held-out AUC on weak labels is 0.86 (`tools/kpm_report.py`).

The ball is missing from roughly 41% of graded frames. Short in-play fouls and throw-ins are difficult to distinguish from a brief slowdown. A ball-velocity change near a player can indicate a deflection, a clearance or control. These ambiguities can shift the boundaries of otherwise plausible possessions. On the public window the detector finds half of the dead-ball frames (recall 0.49, precision 0.93). The stoppage model is trained on other competitions, and the tracking there differs from this match's. The open matches spend 37–55% of graded time dead, and this file is 48% dead. The team-shape model's worst-fold KS gap misses its limit. The labeled public window is too small to estimate the ranking reliably.

## Reproduce the submission

Use Python 3.11.9 and install the exact dependencies from requirements-sonar.txt. Put the organizer-supplied tactical ATD text, ATD XML and Smart Tagging XML in data/tactical, or set MTAH_DATA_DIR to the folder containing tactical. No match assets or Sonar predictions are included in the repository.

```text
python -m pip install -r requirements-sonar.txt
python -m sonar.make_submission --name Sonar --out data/release
python evaluation/validate_submission.py data/release/Sonar.csv
python tools/check_submission.py data/release/Sonar.csv
python tools/repro_check.py --existing-env --expect 2748a02c58b59f5ae30e940dac7a4745
```

Expected CSV MD5 is `2748a02c58b59f5ae30e940dac7a4745`. The stored stoppage weights are committed, so no open-data download is needed to reproduce it. The reproduction check builds twice from independent cold caches, checks both files and compares them with the upload hash. Omit --existing-env to have the script build its own environment. The CSV is written with LF line ends on every operating system.
